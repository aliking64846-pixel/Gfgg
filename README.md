# CyberGuard — مركز الأمن السيبراني

مشروع تعليمي بواجهة عربية. بعض مؤشرات لوحة التحكم والتنبيهات أمثلة تجريبية، ولا تمثل مراقبة أمنية حقيقية.

## الحالة الحالية
- `index.html`: واجهة لوحة التحكم وأقسام التعلم والسجلات وقوائم التحقق والتقارير.
- `server.js`: خادم Express اختياري مع `GET /api/health` و`POST /api/analyze-logs`.
- `package.json`: تشغيل الخادم عبر Node.js.
- `CYBERGUARD_LOCAL_ROADMAP.md`: خطة التطوير المحلي ومراحل الفحص وضوابط الأمان.

## تشغيل النسخة الحالية محلياً
1. ثبّت Node.js 18 أو أحدث.
2. افتح الطرفية داخل مجلد المستودع.
3. نفّذ `npm install`.
4. نفّذ `npm start`.
5. افتح `http://127.0.0.1:3000`.

## واجهات API الحالية
- `GET /api/health`: حالة الخادم.
- `POST /api/analyze-logs`: تحليل نصي أولي للسجلات. هذا تحليل كلمات وعبارات، وليس نظام كشف اختراقات.

## ما لا يفعله الإصدار الحالي
- لا يجري فحصاً فعلياً للمواقع أو عناوين IP أو الشبكات.
- لا يتصل بأدوات SIEM أو EDR.
- لا يجوز اعتبار مؤشرات الصفحة الرئيسية أو التنبيهات الافتراضية نتائج حقيقية.
- GitHub Pages يستضيف ملفات ثابتة فقط، ولا يشغّل خادم Node.js.

## ضوابط الاستخدام
اختبر فقط الأنظمة التي تملكها أو لديك إذن صريح بفحصها. لا ترفع كلمات مرور أو مفاتيح أو سجلات حساسة إلى مستودع عام. راجع ملف خطة التطوير قبل إضافة وحدات فحص جديدة.
