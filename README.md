# CyberGuard — مركز الأمن السيبراني

مشروع تعليمي بواجهة عربية، مع خادم محلي اختياري. بعض مؤشرات لوحة التحكم والتنبيهات في الواجهة الحالية ما زالت تجريبية ولا تمثل مراقبة أمنية حقيقية.

## الملفات الأساسية
- `index.html`: الواجهة الحالية؛ لم يتم تغيير تصميمها.
- `server.js`: خادم Express محلي، وتحليل نصي للسجلات، ونقطة فحص HTTPS اختيارية.
- `site-check.js`: فحص منخفض التأثير لترويسات الحماية لموقع HTTPS عام، مع تحقق DNS ورفض العناوين غير العامة.
- `CYBERGUARD_LOCAL_ROADMAP.md`: مراحل التطوير والقيود الأمنية.

## تشغيل الخادم محلياً
1. ثبّت Node.js 18 أو أحدث.
2. افتح الطرفية داخل مجلد المستودع.
3. نفّذ `npm install`.
4. للتشغيل العادي: `npm start`.
5. افتح `http://127.0.0.1:3000`.

## تفعيل فحص HTTPS الاختياري
الفحص معطّل افتراضياً، ولا يُفعّل إلا عندما تشغّل الخادم محلياً مع متغير البيئة `CYBERGUARD_ENABLE_SCANS=true`.

على Linux / Kali / macOS:
```bash
CYBERGUARD_ENABLE_SCANS=true npm start
```

على Windows PowerShell:
```powershell
$env:CYBERGUARD_ENABLE_SCANS = "true"
npm start
```

ثم أرسل طلب POST إلى `http://127.0.0.1:3000/api/check-website` مع JSON مثل:
```json
{
  "target": "https://example.com",
  "authorized": true
}
```
استبدل `example.com` بموقع تملكه أو لديك إذن صريح لفحصه. يمكن استخدام واجهة مثل curl أو أداة API محلية لإرسال الطلب.

## واجهات API
- `GET /api/health`: حالة الخادم، وهل فحص المواقع مفعّل.
- `POST /api/analyze-logs`: تحليل نصي أولي للسجلات، وليس نظام كشف اختراقات.
- `POST /api/check-website`: فحص HTTPS محدود لترويسات الحماية؛ متاح فقط بعد التفعيل الصريح أعلاه.

## حدود الفحص الحالي
- فحص الموقع لا يحقن حمولات اختبار، ولا يتصفح المسارات، ولا يتبع التحويلات، ولا يفحص المنافذ أو يثبت خلو الموقع من الثغرات.
- يرفض الفحص الروابط غير HTTPS والعناوين التي لا تُحل إلى عناوين IP عامة مسموحة.
- الواجهة لم تُربط بعد بنقطة فحص HTTPS؛ هذه المرحلة توفر API محلياً فقط.
- لا يوجد حتى الآن فحص فعلي لعناوين IP أو الشبكات، ولا تكامل مع Nmap أو OWASP ZAP.
- الأرقام والتنبيهات الافتراضية في الواجهة ليست نتائج فحص حقيقية.
- الخادم مربوط على `127.0.0.1` حتى لا يُعرض كخدمة شبكة عامة عن طريق الخطأ. GitHub Pages يستضيف ملفات ثابتة فقط ولا يشغّل Node.js.

## الاستخدام المسؤول
افحص فقط الأنظمة التي تملكها أو لديك إذن صريح بفحصها. لا ترفع كلمات مرور أو مفاتيح أو سجلات حساسة إلى مستودع عام. هذا المشروع أداة أولية تعليمية وليس بديلاً عن مراجعة أمنية احترافية.
