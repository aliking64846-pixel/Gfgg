# مستقبلي 100

موقع دراسة للمنهج العراقي، مصمم للعمل من المتصفح على الهاتف والحاسوب.

## التشغيل والنشر
- الصفحة الرئيسية: `index.html`
- النشر: GitHub Pages عبر GitHub Actions عند كل تحديث على فرع `main`.
- لا يحتاج المشروع إلى تثبيت Node.js أو تشغيل خادم محلي إذا بقي تطبيقاً ثابتاً بملف HTML.

## ملاحظات مهمة
- افتح الموقع من رابط GitHub Pages، وليس من صفحة عرض الكود في GitHub.
- التقدم المحفوظ داخل المتصفح (إن كان التطبيق يستخدم التخزين المحلي) يبقى عادةً على الجهاز والمتصفح نفسه، ولا ينتقل تلقائياً إلى جهاز آخر.
- لا تضع كلمات مرور أو معلومات شخصية حساسة في بيانات المتصفح.
- قبل إضافة ميزات جديدة إلى `index.html`، اختبر التنقل والأزرار والحفظ على الهاتف وبعد تحديث الصفحة.

## بنية المستودع
- `index.html`: التطبيق الرئيسي.
- `.github/workflows/pages.yml`: نشر الموقع على GitHub Pages.
- `404.html`: صفحة مساعدة عند فتح رابط غير موجود.
