# CyberGuard Local Lab — مختبر الأمن السيبراني المحلي

CyberGuard منصة محلية قابلة للتوسّع، بواجهة عربية، هدفها تسهيل استخدام أدوات الأمن السيبراني على جهازك. هذه النسخة ليست بديلاً كاملاً عن Kali Linux: هي لوحة محلية تربط تشخيصات حقيقية محددة بأدوات النظام، مع توسّع تدريجي.

## التشغيل السهل على Kali Linux / Linux

1. نزّل المستودع إلى جهازك من GitHub.
2. ثبّت Node.js 18 أو أحدث وnpm من مصدر موثوق.
3. افتح الطرفية داخل مجلد المشروع.
4. شغّل:
   ```bash
   bash start-cyberguard.sh
   ```
5. اختر وضع التشخيص فقط، أو فعّل الفحوصات المحدودة بعد قراءة التحذير وتأكيد التصريح.
6. افتح `http://127.0.0.1:3000` على نفس الجهاز.
7. لإيقاف البرنامج اضغط `Ctrl+C` في الطرفية.

التشغيل اليدوي:
```bash
npm install
npm test
npm start
```

لتمكين فحص HTTPS وNmap الاختياري يدوياً على Linux:
```bash
CYBERGUARD_ENABLE_SCANS=true npm start
```

على Windows PowerShell:
```powershell
$env:CYBERGUARD_ENABLE_SCANS = "true"
npm start
```

## ما الذي يعمل فعلياً في هذه النسخة؟

- **معلومات الجهاز المحلية:** يقرأ نظام التشغيل والمعمارية وعدد أنوية المعالج والذاكرة وواجهات الشبكة الحقيقية عبر Node.js.
- **اكتشاف الأدوات المثبتة:** يتحقق من وجود Nmap وcurl وOpenSSL وPython وGit ويعرض أول سطر من الإصدار. لا يشغّل أوامر المستخدم التعسفية.
- **استعلام DNS:** يجلب سجلات IPv4 وIPv6 وMX الحقيقية لنطاق مكتوب، دون فحص منافذ.
- **فحص HTTPS محدود:** عند تفعيل الفحوصات، يرسل طلب HTTPS منخفض التأثير لموقع عام مصرح به ويعرض الحالة وبعض ترويسات الحماية. لا يحقن حمولات ولا يتبع التحويلات.
- **فحص Nmap محدود:** عند تفعيل الفحوصات وتثبيت Nmap، يفحص عنوان IPv4 واحداً فقط، ويقتصر على أكثر 20 منفذاً شيوعاً مع مهلة قصيرة. يتطلب تأكيد التصريح في الواجهة.
- **تحليل السجلات:** تحليل نصي أولي لسطور يرسلها المستخدم؛ ليس محرك كشف اختراقات.
- **اختبارات آلية:** `npm test` يفحص صياغة JavaScript ويشغّل اختبارات الوحدة على القيود الأساسية.

## قيود مهمة

- يجب تشغيل الخادم على الجهاز نفسه؛ GitHub Pages يعرض ملفات الواجهة الثابتة ولا يشغّل Node.js أو Nmap.
- الخادم مربوط بـ `127.0.0.1`، لذا لا يمكن التحكم به من جهاز آخر عبر الشبكة بهذه الإعدادات.
- الفحوصات معطلة افتراضياً، ولا تتاح إلا مع `CYBERGUARD_ENABLE_SCANS=true`.
- فحص Nmap يتطلب تثبيت Nmap على الجهاز ووجوده في `PATH`. لا يثبّت البرنامج أدوات النظام تلقائياً.
- الأرقام والرسوم والتنبيهات في لوحة الرئيسية ما زالت **تجريبية**؛ لا توجد مراقبة مستمرة أو كشف تلقائي أو حظر تهديدات.
- لم تُنفّذ بعد: اكتشاف نطاق كامل، التقاط حزم، تحليل ملفات مشبوهة، تكامل OWASP ZAP، قاعدة بيانات تقارير، أو تشغيل مهام في الخلفية.
- تمت إضافة الاختبارات إلى المستودع، لكن يجب تشغيل `npm test` على جهاز فعلي قبل الاعتماد على هذه النسخة؛ لم يتم التحقق من التشغيل على جهاز المستخدم من خلال GitHub وحده.

## الاستخدام المسؤول

استخدم أدوات الفحص فقط على الأجهزة والمواقع التي تملكها أو لديك تصريح صريح لاختبارها. الفحص المحدود لا يثبت أن النظام آمن، والمنفذ المفتوح لا يعني وجود ثغرة. لا ترفع كلمات مرور أو مفاتيح أو سجلات حساسة إلى مستودع عام.
