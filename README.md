# مستقبلي 100 — الاجتماعيات للثالث المتوسط

نموذج تأسيسي لمشروع تعليمي موجّه للمنهج العراقي، يبدأ بمادة الاجتماعيات للثالث المتوسط.

## الملفات
- `index.html`: واجهة عربية متجاوبة RTL.
- `assets/css/app.css`: تصميم الواجهة.
- `assets/js/app.js`: تفاعلات بسيطة وحفظ قراءة التقدم المحلي.
- `data/social-studies.json`: مخطط بيانات المنهج ومصادره.

## الحالة الحالية
هذه مرحلة تأسيسية للواجهة وتنظيم البيانات. لم يُضف بعد محتوى الكتاب أو أسئلة وزارية، ولم تُنفذ بعد بيئة ثلاثية الأبعاد أو شخصية معلّم متحركة أو محادثة صوتية.

## قاعدة التحقق من المحتوى
1. تأكيد الكتاب والطبعة والسنة من مصدر رسمي موثوق.
2. تسجيل بيانات الغلاف والفهرس وعدد الصفحات بعد التحقق.
3. إدخال الدروس بالاعتماد على الكتاب المعتمد.
4. توثيق كل سؤال وزاري بسنة السؤال ودوره ومصدره عندما تتوفر هذه المعلومات.
5. عدم اختلاق أسماء فصول أو نصوص أسئلة أو إجابات ونسبها إلى المنهج.

## التشغيل
يمكن فتح `index.html` مباشرة أو تفعيل GitHub Pages من إعدادات المستودع لاستخدامه كموقع ثابت. لا يحتاج الإصدار الحالي إلى خادم خلفي.

## التطوير القادم
- التحقق من نسخة الكتاب الرسمية.
- بناء فهرس الفصول والدروس.
- إضافة اختبارات مرتبطة بالمحتوى الموثق.
- إضافة سجل أخطاء ومراجعة متباعدة.
- تطوير مشهد تفاعلي ثلاثي الأبعاد بعد اختبار أساس المحتوى والواجهة.

## حفظ التقدم
يستخدم الإصدار الحالي `localStorage` لقراءة حقول التقدم المحلية، ولا توجد مزامنة سحابية أو حسابات مستخدمين حتى الآن.
